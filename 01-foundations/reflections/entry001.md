## Key Insights
I think the most important insight I have had this week is understanding that web development is not just knowing how to write code. While that is a requirement eventually it's an inevitability actually. The most important thing is to understand that web development is contextual. The web is vast and extensive, an ocean of knowledge and information and an array of services. The end goal is to make web products and technologies discoverable and accessible to all. Therefore as a web developer writes their code this context should always be at the forefront, informing how they write their code for the user, for collaboration, for maintainence and the system infrastructure on which it will be deployed.
