## 🔍 Observations From the Code

**Heading hierarchy in practice.** The document uses `<h1>` for the main page
title, `<h2>` for the shopping list section, and `<h3>` for the remaining
three sections. This reflects a real content hierarchy — the shopping list is
treated as a primary section, the others as equal sub-sections beneath it.
Heading levels communicate structure, not just size.

**Correct list type choices.** The shopping list and dream destinations use
`<ul>` — order is irrelevant for both. The to-do list and movies list use
`<ol>` — the to-do list implies a sequence of tasks and the movies list is a
ranked top five. The semantic choice matches the nature of each list's content.

**Introductory paragraph.** Adding a `<p>` element before the lists to
introduce the page content is good structural practice. It gives the page
context and demonstrates that text elements and list elements can coexist and
complement each other within `<body>`.
