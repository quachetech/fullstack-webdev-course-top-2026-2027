## 📚 What I Learned Today

A **website** is a collection of related web pages. A **web server** is a computer that hosts one or more websites.A **search engine** is a web service that helps you find web pages, websites, and information on the web.

**Key Takeaways:**
- Web pages of the same website share a common **domain name** (e.g., `theodinproject.com`), are **interconnected** via links (navigation bars, buttons, linked text) & serve a **common purpose** (teaching, e-commerce, social networking, etc.)
- A **web server** 
- **Hosts** one or more websites (stores their files on its SSD)
- **Serves** web pages to users' browsers when requested
- Has an **IP address** (which domain names point to via DNS)
- **Website =** Collection of web pages (the CONTENT) 
- **Web server =** Computer hosting the website (the MACHINE)
- **You use a BROWSER to access a SEARCH ENGINE.**

## 🧠 Feynman Explanation

[Day 6: Websites, Web Severs & Search Engines](https://youtu.be/)

**In simple terms:**  
- A website is a collection of webpages that are related and serving a common goal or purpose.
- All the webpages of the same website share the same domain name but have unique URLs.
- The file path and the file name of each page differentiate each page's URL
- The webpages of the same website are interconnected through links on the menu, navigation bars or buttons or linked text content.
- A web server is a computer that hosts one or more websites.
- The web server is said to host because it has the website's files saved on it SSD and when we search for a webpage or website it is the server that serves these files which are displayed in the web browser. 
- A search engine is a web service that enables us to search for information on the web. 
- A search engine is different from a web browser because the search engine is a web service while a web browser is a software porgram that displays webpages and other resources on the computer. 
- A search engine can be found on a website or in the address bar of a web browser.
