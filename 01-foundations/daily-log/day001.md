## 📚 What I Learned Today

Today's lesson was on web development. Web development is basicallz the building & maintaining of websites. Websites have the front end & the back end. Front end developers use HTML, CSS & JavaScript to create the content, present the content and add interactivity to websites creating seamless & smooth user experience. While the back end developers work with programming languages such as Java, Python, Ruby & Javascript to manipulate the program data which is stored on the server and enables the websites to run smoothly even as number of users increases. Then here are full-stack developers who are comfortable to work with both front and back ends.

**Key Takeaways:**
- Front End is all about user interface and user experience and is developed by front end devlopers
- Back end is all about storing and serving program data as well as creating capacity of the site for large numbers of users. This is developed by back end developers
- Full-stack developers are competent in frond end and back end development
