## 📚 What I Learned Today

So in today's lesson, I covered browsing the web but looking specifically at the webpage. It is a simple HTML document displayed by a browser and can embed a variety of different types of resources like style information which controls it's look and feel, script which adds interactivity to the page, as well as media that is images sounds and videos. 

Browsers can also display other documents such as PDF files and other resources such as images and videos but the term webpage specifically refers to an HTML document. so each webpage is found in a unique location and has web address called a URL, and to access the page you just type the address in the browser's address bar.

**Uniform Resource Locator (URL)** is a string of text that specifies where resources (such as a video, image or webpage) can be found on the internet. 

**Key Takeaways:**
- URLs look like file paths on my computer—and they work the same way!
- **Example:**
```
https://theodinproject.com/lessons/foundations-how-does-the-web-work
```

**Structure:**

| Part | What It Is | Purpose |
|------|-----------|---------|
| `https://` | **Protocol** | Tells the browser HOW to access the resource (securely) |
| `theodinproject.com` | **Domain Name** | Alias for the server's IP address (which server to contact) |
| `/lessons/foundations-how-does-the-web-work` | **Path** | Where the file is stored on the server (like a directory path) |

**In simple terms:**  
- A webpage is an HTML document displayed in a web browser.
- It is a file stored on a web sever's SSD and we access it using it's URL.
- A URL is a string of text displayed in the browser's address bar that shows the us 3 things
    1. The protocol that the browser is using in order for us to access this webpage such as HTTPS which means "securely provide access to this webpage"
    2. The domain name which is the alias to the web server's IP address. This enables the browser (from our computer) to communicate with the web server on which the webpage whose access we are requesting for is stored.
    3. The file path which is similar to our local directory system on our computer. The webpage being a file stored on the web server will be stored in a directory and therefor the file path informs the server the exact location and the specific file we are requesting access to.
- A webpage also can embed various forms of resources like style information, scripts and media. 
    - The style information informs the appearance and presentation of the webpage (colours, fonts and layout of the content)
    - The scripts add interactivity to the webpage (alert messages, forms, etc)
    - The media can be images, sounds or videos that can be part of the various forms of content resources found on the webpage.
