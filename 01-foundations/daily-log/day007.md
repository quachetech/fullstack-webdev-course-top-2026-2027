## 🧠 Feynman Explanation

[Day 7: How the Web Works]()

**How the Web Works (Simple Terms):**

When you visit a website, your browser asks the web server for files using HTTP (a communication protocol). The server sends back HTML (the structure), CSS (the styling), and JavaScript (the interactivity). Your browser combines these to display the webpage.

HyperText makes the web powerful—unlike books with sequential pages, web pages are interconnected. You click links to jump between related information, creating your own path through content.

**Key Insight:** HTML is the foundational structural language because it defines what exists on the page. CSS and JavaScript enhance it, but without HTML, there's nothing to enhance.
