## 🌐 Links & Images

### Concept Summary

The anchor element `<a>` creates links in HTML. The `href` attribute provides
the destination — without it the element renders as plain text with no
function. The `target="_blank"` attribute opens links in a new tab and should
always be paired with `rel="noreferrer"` to prevent tabnabbing security
vulnerabilities.

Two types of links:
- **Absolute** — full URL including scheme and domain, used for external sites
- **Relative** — file path relative to the current file, used for internal pages

The `<img>` element is a void element that embeds images using the `src`
attribute. The `alt` attribute provides descriptive fallback text for
accessibility and failed loads. Declaring `height` and `width` prevents
content jumping during page load by reserving the correct space before the
image downloads.

### Practical Summary

Built a two-page website with the following structure:

```
links-images/
├── index.html
├── pages/
│   └── about.html
└── images/
    └── dog.jpg
```

**Key learning from the practical:** The same image required two different
relative paths depending on which file was referencing it. `index.html` used
`./images/dog.jpg` because it sits at the same level as `images/`. `about.html`
inside `pages/` used `../images/dog.jpg` because it first needed to climb up
one directory level before reaching `images/`. Relative paths describe a
journey through the file system — they are positional, not fixed.

Moving `about.html` from the root into `pages/` immediately broke the
relative link pointing to it from `index.html` and required updating the path.
A practical lesson in why project structure decisions made early matter.

## 📝 Commit Messages

Good commit messages are a professional discipline, not a formality. A
well-written commit history serves as a project journal — useful for
collaboration, debugging, returning to old work, and demonstrating professional
habits to employers or clients.

**Structure:** Subject and body separated by a blank line.

```
Add alt text to all images in the links-images project

Images were missing alt attributes creating accessibility gaps for
screen reader users. Added descriptive alt text to all img elements
across index.html and about.html.
```

**The seven rules:**
1. Separate subject from body with a blank line
2. Limit subject to 50 characters
3. Capitalize the subject line
4. No period at the end of the subject line
5. Use the imperative mood — "Fix bug" not "Fixed bug"
6. Wrap body at 72 characters
7. Body explains what and why — not how

**Multi-line commits:** Running `git commit` without `-m` opens VS Code to
write a subject and body. Save and close the tab to create the commit.

## 💡 Key Insights

**Relative paths are journeys.** `./` means "from here." `../` means "go up
one level then continue." The path describes movement through the directory
tree — the same movement used in the terminal with `cd`. The CLI and HTML
share the same underlying logic.

**The commit message is a quality check.** If writing a clear subject line
for a commit is difficult, it usually means too many unrelated changes were
bundled together. The act of writing the message reveals whether the commit
was truly atomic or not.

**Alt text is not optional.** Every image that cannot be described by its
surrounding content needs an `alt` attribute. It is an accessibility
requirement, not a suggestion.
