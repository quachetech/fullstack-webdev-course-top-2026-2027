## 📚 What I Learned Today

**How the internet works**
- The internet is hardware that enables computer devices to connect, communicate and share information. 
- All computer devices connected to the internet are assigned **IP addresses** which enable the computer devices to identifz one another enabling information to reach intended recipients. 
- **Domain Names** are IP address aliases e.g. google.com.
- Servers are computers directly connected to the internet and they store webpages and websites.
- Some servers are dedicated to a single website like Google while others host several small websites.

**Key Takeaways:**
- The internet is not the web. The web is a service while the internet is infrastructure.
- IP addresses are assigned to computers not websites and only in the case of major websites like Google that have dedicated servers all to themselves do we have google.com corresponding to an IP address.
- When a server host several websites these websites can not have a corresponding IP address but instead are asigned host headers. This is because the IP address is onlz assigned to a computer device.

## 🧠 Feynman Explanation

[Day 3: How The Internet Works](https://youtu.be/m0UeSgzwFBg)

**In simple terms:**  
- The internet is hardware ie physical infrastructure that enables computers worldwide to connect, communicate and share information. It is a network of networks connected to each other.
- The internet is used to share information therefore in order for information to reach the intended recipient a system of IP addresses is used. 
- The IP address system is similar to the postal system. Each computer device connected to the internet is assigned an IP address in order for them to recognise and identify or find each other on the network.
- Picture each computer as a house with each house having an address of its own such that when you send a letter via the postal service it reaches the intended recipient because you would have written down their exact address on the envelop 
- No two houses can have the same address similarly each computer device's IP address is unique.
- An IP address is a string of numbers and these numbers are used by computers much easier than by humans, so a domain name is therefore assigned to each IP address in order for it to be easier for us humans to identify computers on the internet.
- So therefor the Domain Name System works as an address book which matches the domain names to their corresponding IP addresses. 
- The Domain Name System (DNS) is managed on servers.
- A server is a special computer, directly connected to the internet. Servers are also useful for data storage. Servers have internal storage memory known as Solid State Drive (SSD) on which data is stored including files like webpages and websites.
- A client is a computer connected to the internet indirectly via an ISP.
- An Internet Service Provider (ISP) is an organisation that provides the service of connecting clients to the internet using its servers.
- Where the internet intersects there is a router, which is a special computer device whose job is to direct or channel data.
- Routers are important in ensuring that information is not lost or directed to the wrong recipient
- Most websites are stored on servers together with many other websites on the same server and therefore  have to share an IP address. But to avoid confusion each of these websites have Host Headers assigned to them, enabling the server to be able to identify the website being requested. 
- Large websites like YouTube for example have entire data centres and servers dedicated to them therefore they have an IP address that matches their domain names.
