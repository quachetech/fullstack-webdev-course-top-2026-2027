## 🛠️ How It Works

## Day 4: Browsing the Web Basics

### 🧠 Key Concepts

**Web Page:** A single document written in HTML that displays in a browser  
**Example:** One Google search results page

**Website:** A collection of web pages linked together  
**Example:** All of Google (homepage, Maps, Gmail, etc.)

**Web Server:** A computer that stores websites and serves them over the internet  
**Connection to Day 3:** This is the "server" I learned about—has IP address, stores data on SSD

**Web Service:** Software that performs a function over the internet  
**Examples:** Gmail (sends emails), Weather API (provides weather data), YouTube (streams videos)

**Search Engine:** A web service that helps you find other web pages  
**Examples:** Google, Bing, DuckDuckGo

---

### 🏨 The Hostel Analogy (Web Hosting Explained)

**A server hosting multiple websites is like a hostel:**

- **The building** = The server (has one street address = IP address)
- **Each room** = Each website stored on that server
- **Room numbers** = Host headers (how the server knows which website to serve)

**Example:**
- IP Address: `192.168.1.1` (the building's address)
- Website 1: `bakery.com` → Room 1 (host header)
- Website 2: `blog.com` → Room 2 (host header)
- Website 3: `shop.com` → Room 3 (host header)

When you visit `bakery.com`, the server checks the host header, sees "Room 1," and serves the bakery website.

### 🤔 Questions I Explored

**"Is email a web service?"**  
Yes! Gmail, Outlook, etc. are web services—they perform a function (sending/receiving messages) over the internet.

**"Is Google Drive a web service?"**  
Yes! It stores files and lets you upload/download—that's a function provided over the internet.

**"What's the difference between a website and a web service?"**  
- Some websites are JUST static pages (pure content, no functions)
- Some websites are ALSO web services (they display pages AND perform functions)
- Some web services have NO visible website (just software responding to requests from other software)
