## 🎯 What Is This?

In a programming environment it is essential to ask well-formed questions with as much context as needed, so as to get the most out of asking for help. Help others help you.

---

## 🧠 Why Does It Matter?

Web Development is a collaborative effort and it is common to come across challenges in this line of work. Knowing how to ask for help thus becomes an essential skill just as much as the coding itself is. 

---

## 🛠️ How It Works

### Tips for getting the best help possible. 
**1. Always provide your code and surrounding context**
- It's essential to provide you a code error message terminal command serveroutput and other relevant details.
- Provide as much context as possible and zero in on the specific problem such as pointing people to a specific function or line number in your code. This makes it easier for others to help. 
**2. Ask about the problem at hand not the solution itself** 
- Figuring out how to solve assignment is part of the learning proces, so do not ask how to solve the assignment. 
- Share what you've already attempted him showing a specific problem share your pseudocode so people can nudge you in the right direction or correct any misunderstandings. 
**3. Don't Take asking for more context to heart.**
- There's probably good reason why they need more information Trust their judgement and experience  
**4. Don't ask to ask just ask.** 
- This can put people off from wanting to help you. 
**5. Don't ask about your attempted solution (the XY problem).** 
- Use the waste of time because what you might think is a solution is actually nowhere near the solution of the actual problem explain the issue in for providing the attempted Solutions and let people help you.
### How to ask technical questions
**Before asking a question** 
1. Do your own research. 
2. Help yourself 
- Adjust your expectations, it's okay not to know the whole solution. 
- Break down the problem into small pieces and write it out in pseudocode 
- Research a sub problem (a part of the problem not all of it) 
- Examine error messages, learn about the error and its location use Google. 
- Triple check terminal command 
a. starting at the Beginning reread the directions 
b. compared directions to your terminal history to ensure that you did not skip anything 
c. copy and paste the exact command from the lessons provided to prevent typos. 
d. use the command `pwd` to confirm that you are in the right directory 
e. alternatively research and confirm that you are using the correct commands 
- Review previous lessons 
- check for typos, 
- debug your code 
- read documentation thoroughly 
- know when to take a break and 
- talk through your code line by line. 
3. Pick the most relevant help Channel 
4. Prepare your question 
- provide a link to the lesson or project in the curriculum this provides the surrounding context and knowledge and skill level 
- provide code pseudocode or other relevant information use external service if you have more than a few lines of code to share CodePen for basic HTML CSS JavaScript,  Replit for JavaScript and Ruby, Codesandbox for Webpack/React and Pastebin for error messages or server output. 
- explain the problem 
- describe what you are expecting and summarise what you have tried.
