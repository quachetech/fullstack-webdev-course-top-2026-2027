### 🌐 What is a Website?

A **website** is a collection of related web pages that:
- Share a common **domain name** (e.g., `theodinproject.com`)
- Are **interconnected** via links (navigation bars, buttons, linked text)
- Serve a **common purpose** (teaching, e-commerce, social networking, etc.)

**Example:**  
The Odin Project website has lessons, projects, and resources—all connected and serving the goal of teaching web development.

---

### 🔗 URL Uniqueness Across a Website

**Key insight from Day 5:** Each webpage has a **unique URL**.

**What stays the same:**
- Protocol: `https://`
- Domain name: `theodinproject.com`

**What changes:**
- File path: `/lessons/foundations-html-css` vs `/projects/calculator`

**The file path is what makes each webpage's URL unique.**

---

### 💻 What is a Web Server?

A **web server** is a computer that:
- **Hosts** one or more websites (stores their files on its SSD)
- **Serves** web pages to users' browsers when requested
- Has an **IP address** (which domain names point to via DNS)

**My hostel analogy (from Day 3):**
- Web server = Building (has one address = IP address)
- Each website = Room in the building
- Host header = Room number (for shared hosting)

---

### 🆚 Website vs Web Server

**Common confusion:**

**Website =** Collection of web pages (the CONTENT)  
**Web server =** Computer hosting the website (the MACHINE)

**Real-world example:**

- "My website is not responding" → Problem connecting to the **server** hosting the website
- "The web server is down" → ALL websites on that server are affected

---

### 🔍 What is a Search Engine?

A **search engine** is a web service that helps you find web pages, websites, and information on the web.

**Examples:**
- General: Google, Bing, DuckDuckGo
- Specialized: YouTube (videos), Google Scholar (academic papers), Amazon (products)

**My library analogy:**  
Just like a library catalog helps you find books by searching for titles/topics, a search engine helps you find webpages by searching for keywords.

---

### 🆚 Search Engine vs Browser

**Common beginner mistake:** Confusing the two.

**Browser** (Chrome, Firefox, Safari):  
Software that **displays** web pages

**Search Engine** (Google, Bing):  
Web service that **finds** web pages

**You use a BROWSER to access a SEARCH ENGINE.**

---

### 💡 Key Takeaways

- A website = collection of related pages with a shared domain
- Each page has a unique URL (different file path)
- Web servers = machines that host websites
- Search engines = web services that help you find content
- Browsers ≠ Search engines (display vs search)

**Everything connects.** 🧩
